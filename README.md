# Conversa 🇧🇷

Free spoken-conversation practice in Brazilian Portuguese. Talk to it, it replies in a native Brazilian voice and corrects your mistakes as you go.

- Speech recognition: browser (Chrome / Android)
- Conversation + corrections: Google Gemini API (free tier, bring your own key from https://aistudio.google.com/apikey — stored only on your device)
- Voice: your device's pt-BR text-to-speech voice (Android: Settings → Accessibility → Text-to-speech → Google → install Português (Brasil))
